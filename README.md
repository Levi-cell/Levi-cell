## Projetos em Destaque

### Disparador de Promoções

Sistema Python para gerenciar clientes e automatizar disparos pelo WhatsApp Web usando Selenium, Chrome remoto, MySQL e interface em Tkinter.

O projeto resolve um problema real de operação: manter uma lista de contatos, importar base do Google Contacts, validar números, controlar blacklist, evitar disparos duplicados e enviar mensagens com ou sem mídia.

Tecnologias: Python, Selenium, MySQL, Tkinter, PyAutoGUI, PyInstaller.

Link: [github.com/Levi-cell/Disparador](https://github.com/Levi-cell/Disparador)

### LinkExtractor

Aplicação Django com lógica de web crawler para buscar links relacionados a uma URL informada pelo usuário. Foi desenvolvido como projeto final de formação, explorando backend web, scraping, organização de resultados e interface web.

Tecnologias: Python, Django, HTML, CSS, Web Scraping.

Link: [github.com/Levi-cell/LinkExtractor](https://github.com/Levi-cell/LinkExtractor)

### Livraria Django

Projeto web/API para gerenciamento de uma livraria, com estrutura Django, arquivos de deploy e configuração para ambiente web.

Tecnologias: Python, Django, JavaScript, CSS, Docker, Gunicorn, Whitenoise.

Link: [github.com/Levi-cell/livraria-django](https://github.com/Levi-cell/livraria-django)

### Rick and Morty Django

Projeto Django que trabalha com dados do universo Rick and Morty e utiliza web scraping assíncrono. É uma boa demonstração de consumo/processamento de dados e organização de aplicação web.

Tecnologias: Python, Django, HTML, Docker, Web Scraping.

Link: [github.com/Levi-cell/RickAndMorty](https://github.com/Levi-cell/RickAndMorty)

### W5i Desafio

Desafio técnico envolvendo lógica de programação em Python e banco de dados. É útil para demonstrar raciocínio lógico, manipulação de dados e solução de problemas orientada a requisitos.

Tecnologias: Python, Banco de Dados, Docker.

Link: [github.com/Levi-cell/W5iDesafio](https://github.com/Levi-cell/W5iDesafio)

### Projetos SQL

Coleção de estudos e exercícios em SQL envolvendo criação de tabelas, inserção de dados, consultas, transações e controle de acesso.

Tecnologias: SQL, T-SQL, modelagem relacional.

Link: [github.com/Levi-cell/ProjetosSQL](https://github.com/Levi-cell/ProjetosSQL)
